# 🐧 Linux Notes (DevOps Focus)

## 📌 What is Linux?
Linux is an open-source operating system widely used in servers, cloud, and DevOps environments.

---

## 🎯 Why Linux for DevOps?
- Most servers run Linux
- Required for Docker & Kubernetes
- Used in CI/CD pipelines
- Powerful command-line tools

---

## 🧱 File System Structure

/        → Root  
/home    → User files  
/etc     → Config files  
/var     → Logs  
/bin     → Basic commands  
/tmp     → Temporary files  

---

## 📂 File Permissions

Format:
-rwxr-xr--

r = read  
w = write  
x = execute  

---

## 👤 User Types
- root (admin)
- normal user
- service users

---

## ⚙️ Package Management
